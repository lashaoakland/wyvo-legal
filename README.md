# Wyvo — legal pages

Privacy Policy and Terms of Service for the **Wyvo** mobile app, published
via GitHub Pages so the App Store and Google Play have a public URL to link.

- https://lashaoakland.github.io/wyvo-legal/privacy-policy.html
- https://lashaoakland.github.io/wyvo-legal/terms-of-service.html
- https://lashaoakland.github.io/wyvo-legal/support.html (the App Store's Support URL)

The source of truth is `privacy-policy.md` / `terms-of-service.md` /
`support.md` in the Wyvo app repository (private). The HTML here is
generated from those by `python3 scripts/build-legal-pages.py` in that
repo — edit the Markdown there, regenerate, and push here.
